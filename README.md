# YYSLS-Package

适配于燕云十六声的3Dmigoto DX11的Package包

# 说明

由于版本更新后，新增了一套布料解算系统，所以生成的Mod不得不对其Shader进行修改，从而让Mod替换正常生效。

代价就是所有替换模型的部位布料解算都会失效。

本包内置全局 Check。Mod 仍须匹配当前游戏的资源哈希、绘制区间及顶点布局。

## v0.1.5：替换网格的阴影适配

`d3dx.ini` 末尾内置阴影 ShaderRegex 和只读标记资源。对于符合规则的阴影 VS，Mod 可在主动重绘时绕过原模型的变形位置读取，继续使用替换网格的位置；骨骼蒙皮和阴影投影保留游戏原有逻辑。

目前已在长裙上实测不再闪烁，删减部分的阴影随之变化。内裙、衣袖等相同 Shader 结构已接入测试；这不代表所有服装、LOD 或阴影 Shader 都已验证。结构不匹配时不应用修补。

### Mod 接入

仅更新 Package 不会自动修改旧 Mod。导出器或 Mod 作者需要在每一次替换网格的显式重绘前后加入以下命令，原有 VB/IB 绑定及绘制参数保持各自 Mod 的设置：

```ini
; 在替换 VB/IB 绑定之后、显式重绘之前：
if vs == 823115
    vs-t119 = ref ResourceYYSLSShadowMarkerV2
endif

; 此处保留原 Mod 的 drawindexed 等重绘命令及参数。

; 重绘结束后立即解除标记：
if vs == 823115
    vs-t119 = null
endif
```

`823115` 是 ShaderRegex 匹配成功后设置的标识，不是 Shader 哈希。`ResourceYYSLSShadowMarkerV2` 定义于主配置，Mod 可以直接引用；若 Mod 已有同名局部标记资源，则优先使用局部资源，内容须同为单个 `R32_FLOAT` 值 `1.0`。

兼容约定：

- 为此功能预留 VS 槽位 `t119` 和标识 `823115`；不要用于其他用途。
- 只包住替换网格的主动重绘，不在全局 Check 中给所有绘制绑定标记。不需要新增 `vs-t11` 的 Check。
- 使用该通道时，`t119` 应原本未绑定；每次重绘结束都须解除标记。
- ShaderFixes 中同哈希的手工替换优先于 ShaderRegex。测试本功能时，将对应手工替换文件备份移出 ShaderFixes，并移除独立安装的同名试验规则，避免重复配置。
- 首次安装或切换规则后建议重启游戏。游戏更新改变 Shader 结构或数据布局后，仍可能需要适配。

此版本提供公共规则和接入协议，尚未包含 MIMIBlender 导出器的自动接入更新。
